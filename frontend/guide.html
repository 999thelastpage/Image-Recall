Recall guide

This guide tells you how to use Recall and how Recall operates. It follows the rules of ASD-STE100: short sentences, active verbs and one idea in each sentence.

1. Purpose

You can remember a photo but not know all its details. Your description can be vague. One detail can be wrong.

A simple search compares all your words with each photo. It does not ask you which words can be wrong.

Recall also searches without each detail. Recall can also ask you about the details. You can then correct a detail, or tell Recall that you do not trust it.

2. Find a photo

Compare two searches

  1. Select Compare both.
  2. Type what you remember.
  3. Select Search my photos.
  4. Look at the two lists. Each list shows the result of one type of search.

Correct your description

  1. Select Ask me questions.
  2. Type what you remember.
  3. Select Search my photos.
  4. Answer each question. Recall asks a maximum of 3 questions.
  5. If you do not know the answer, select Not sure.
  6. Look at the final list of 10 photos.

Note: Recall can ask no questions. This can occur when Recall does not find separate details in your description.

3. How Recall operates

Prepare the library

Recall does these steps one time for each photo library.

  1. MetaCLIP makes a list of 768 numbers for each photo.
  2. Recall keeps these lists in an index.

Do the search

  1. Muse Spark divides your sentence into clues. If Muse Spark is not available, a local word list does this work.
  2. MetaCLIP makes a list of numbers for your sentence.
  3. Recall compares this list with all photos in the index.
  4. Recall does more searches. Each search removes one clue. Other searches try a different colour.
  5. Recall puts all scores on one scale.
  6. Recall joins the results into one list. Your full sentence has the most weight.

Use your answers

  1. If you give a new value, Recall changes your sentence and searches again. This search gets the most weight.
  2. If you do not trust a clue, Recall removes it from the sentence that it searches. Then Recall searches again.
  3. If you select Not sure about the main subject, Recall does not trust that clue.
  4. If you select Not sure about a new value, Recall makes no correction.

Make the final list

Recall does these steps when you use Ask me questions.

  1. Muse Spark looks at the top 40 photos and gives each photo a score.
  2. Recall mixes this score with the search score. The Muse Spark score has 65% of the weight.
  3. Recall shows the top 10 photos.
  4. You can ask for evidence on the top 3 photos. Muse Spark or SAM 3.1 finds the object in each photo.

Note: Recall needs access to Muse Spark. Without this access, Recall uses the local word list, and it does not show evidence.

How we made this test

  • A computer program made each wrong description and gave each correction.
  • The program knows the correct detail.
  • The objects are on the Recall answer list.
  • The AI check is Muse Spark. It gives both searches the same check.
  • “New searches” are searches that we did not use to tune Recall.

6. Next step: show near matches

You can look for a photo and not know the correct word. Recall can use this idea in a new way. It can change “a car parked in grass” to “a vehicle parked in grass”. It can then show these near matches in the list. You do not answer a question.

We tested this idea in an experiment. It is not in Recall at this time. The test had 120 descriptions, each with a wrong object, and 5,000 photos. A word list that we wrote for this test gives the general words.

7. Terms

Clue
One part of your description, for example “red bus” or “in grass”.
MetaCLIP
A Meta model. It changes photos and words into lists of numbers.
Muse Spark
A Meta model. It reads text and looks at photos.
SAM 3.1
A Meta model. It finds objects in a photo.
Top 10
The first 10 photos in a list.
